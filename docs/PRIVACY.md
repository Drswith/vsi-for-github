# Privacy policy

VSI for GitHub reads the visible names of repository files and folders on `https://github.com` to choose and display matching icons. The extension processes those names locally in the browser.

VSI for GitHub uses those names only to display matching icons. It does not collect, transmit, store, or sync page content, repository names, browsing activity, account information, or settings. It does not make network requests, use analytics, or load remote code. Icon mappings and SVG assets are included in the installed extension package.

The extension runs only on GitHub pages and has no additional browser API permissions. Removing the extension removes its code; it has no extension storage to clear.

For questions about this policy, open an issue in the [VSI for GitHub repository](https://github.com/Drswith/vsi-for-github/issues).
